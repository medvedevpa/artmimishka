ART MIMISHKA — v20 · точечные изменения для GitHub

  assets/css/polish-v16.css

Что изменено:
1) Бестселлеры: вертикальные карточки с квадратными фото; компактный современный стиль; три карточки в одном ряду даже на узких телефонах.
2) Переход из каталога к разделу «Творческая мастерская Ольги Медведевой»: длинный сливовый градиент вместо резкой границы/волны.
3) Админка: несколько дополнительных фотографий для товаров и упаковки, видео по ссылке либо небольшое MP4/WEBM до 1,5 МБ; предпросмотр галереи и видео.
4) Предпросмотр при выборе вкладки «Упаковка» теперь показывает именно выбранную упаковку, а не последний товар.
5) Структурированные поля: высота, длина, ширина (см), вес (г). Эти данные сохраняются в каталоге и показываются на страницах изделий.
6) Галерея фотографий и видео на страницах товаров после публикации данных из редактора.

Как обновить сайт:
- Откройте репозиторий medvedevpa/artmimishka в GitHub.
- Замените перечисленные 5 файлов, сохранив структуру папок. Другие файлы менять не нужно.
- Подождите публикации GitHub Pages и обновите сайт с очисткой кэша (Ctrl+Shift+R).

Важно: админка сохраняет черновики в браузере; чтобы изменения стали видны покупателям, нажмите «Скачать данные для GitHub (ZIP)» и загрузите экспортированные assets/data/*.js в репозиторий.
Видео больше 1,5 МБ лучше размещать отдельно и указывать прямую ссылку на MP4/WEBM. Файлы изображений внутри черновика могут занимать место в localStorage; регулярно сохраняйте резервную копию JSON.

Доставка: автоматический СДЭК НЕ подключён. Стоимость доставки уточняется индивидуально в переписке.
