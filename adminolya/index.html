Открыть сайт ↗
Как обновить сайт: заполните карточки → нажмите «Скачать данные для GitHub (ZIP)» → замените скачанные файлы assets/data/catalog.js, assets/data/courses.js и assets/data/packaging.js на хостинге или GitHub. Само редактирование здесь не публикует изменения в интернете. Вход с кодом защищает только от случайного доступа. Для полноценной защиты и автоматической публикации потребуется серверная авторизация.
