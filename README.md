# ART MIMISHKA — Atelier v16

Сайт творческой мастерской Ольги Медведевой. Магазин статический, работает даже при открытии index.html с компьютера.

## Что нового
- Из каталога удалены пять позиций по запросу, а из раздела курсов — «Куколка Ханна».
- Главный баннер заменён полноразмерной исходной композицией, с отдельным чётким заголовком и плавным переходом к бестселлерам.
- У блока о мастерской фиолетовые градиенты плавно переходят на фотографию и в нижний раздел.
- В корзине после добавления товара показываются фотографии и весь текущий список с количеством и суммой.
- Добавлен редактор каталога: `atelier-olya-9e7b/index.html`.

## Редактор каталога (для Оли)
1. Откройте `atelier-olya-9e7b/index.html` в браузере.
2. Выберите существующий товар или нажмите «+», чтобы добавить новый. Можно менять название, категорию, стоимость, характеристики, варианты, доступность, фото и описание.
3. Нажмите «Сохранить черновик». Черновик хранится только в браузере этого устройства.
4. Нажмите «Скачать файл для сайта». Скачанный файл называется `catalog.js`.
5. В папке сайта замените **`assets/data/catalog.js`** скачанным файлом. Для опубликованного сайта замените тот же файл в репозитории GitHub и опубликуйте изменения. Обновятся карточки каталога и корзина.
6. Перед переносом на другой компьютер скачайте резервную копию JSON и импортируйте её в редактор.

**Важно:** страница редактора не имеет серверной авторизации и не является защищённой. Адрес не указан в меню и поставлена мета-директива `noindex`, но любой знающий ссылку может открыть редактор; он не может автоматически изменить опубликованный сайт без прав на репозиторий. Не вводите сюда пароли GitHub. Для полноценного онлайн-кабинета потребуется серверное хранение и аутентификация.

### Фото
При выборе фото редактор сохраняет его в компактном WEBP прямо внутри `catalog.js` (data URL), чтобы не приходилось отдельно загружать файлы изображений. При большом каталоге файл увеличивается; для десятков новых товаров рекомендуется перейти на хранение фото отдельными файлами через будущую CMS.

### Данные товаров
Единственный источник данных для ленты каталога и корзины: `assets/data/catalog.js`. Резервный JSON: `assets/data/products.json` (начальный снимок, не обновляется автоматически). Старые товарные URL сохранены, новые товары используют `products/view/index.html?id=…`.

## Публикация
Сайт можно открыть локально — `index.html`. Для предпросмотра через localhost используйте `python -m http.server 8000`. Загрузите содержимое папки на GitHub Pages / хостинг, оставив `index.html` в корне.

## Перед публичным запуском
Проверьте наличие и цены, юридические документы, а также коммерческие права на образы и названия в тематике Harry Potter. Приём оплаты через сайт не осуществляется.
