# ART MIMISHKA — Atelier Fidelity v15

Главная пересобрана с приоритетом точного визуального сходства с утверждённым макетом.

- Первый экран основан на утверждённой художественной композиции без повторной перерисовки изделий.
- Бестселлеры: горизонтальные рабочие карточки с аккуратными золотыми рамками.
- Каталог: полный список, квадратные реальные фотографии, фильтрация и сортировка.
- Изогнутые переходы между секциями выполнены в SVG; линии остаются чёткими на любых экранах.
- Реальный портрет Оли, три мастер-класса, оформление заказов, реквизиты.
- Корзина, варианты товаров, ароматы свечей и переходы в Telegram/MAX сохранены.

## Локальный запуск

Распакуйте архив полностью и откройте `index.html`. Для прямых переходов между страницами рекомендуем использовать локальный статический сервер или сайт после публикации, но основные страницы доступны локально.

## Перед публикацией

Не добавляйте искусственно завышенные зачёркнутые цены — отображайте скидки только относительно действительных прежних цен. Проверьте юридические тексты, доступность товаров, лицензирование образов и актуальные условия заказа.
